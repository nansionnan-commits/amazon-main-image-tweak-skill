# 产品 → 角落元素 对照表

> 主图微改的核心判断：**这个产品用在什么地方？把那个"地方"的一小片纹理放进角落。**

## 选元素的三个标准

| 标准 | 说明 |
|---|---|
| **能被秒懂** | 买家看一眼就联想到使用场景，不需要解释 |
| **不抢主体** | 虚焦、低对比、单色系，占画面 ≤20% |
| **不产生误导** | 不能让人以为"附赠"或"包含"该物品 |

## 反面案例（不要放）

| ❌ 不要 | 原因 |
|---|---|
| 另一个完整产品 | 会被误认为"买一送一" |
| 带品牌 logo 的物品 | 侵权风险 |
| 带文字/价格牌的物品 | 违反主图规范 |
| 人体局部（手/脸） | 容易分散注意力且引发审核 |
| 大面积场景 | 主图应保持干净，场景图放副图 |
| 强对比色道具 | 抢主体视线 |

---

## 角落选择原则

| 产品在画面中的位置 | 元素放哪 |
|---|---|
| 居中 | 左下 或 右下（不要正上，会压头） |
| 偏右 | **左下**（平衡构图） |
| 偏左 | **右下** |
| 占满画面 | 不放元素，改用副图做场景 |

---

## 一句话总结

> **元素是"暗示"，不是"布景"。** 一片毛衣纹理不等于一件毛衣，目的是让买家的大脑补全使用场景。
